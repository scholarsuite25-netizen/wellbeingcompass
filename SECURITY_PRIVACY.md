# Security & Privacy Requirements

## Security
- Secure authentication
- RBAC
- Password hashing
- Session protection
- CSRF protection
- XSS prevention
- SQL/NoSQL injection prevention
- Input validation
- Output encoding
- Rate limiting
- Secure uploads
- MIME/type validation
- File-size limits
- Audit logs
- Dependency monitoring
- Secure headers
- Backup and recovery

## Privacy
Collect the minimum data necessary.

Do not expose:
- Private health information
- Private messages
- Internal reviewer notes
- User identifiers in public URLs
- Sensitive search terms in analytics

Provide appropriate privacy notices, consent mechanisms and retention controls based on applicable law and deployment jurisdiction.

## Special principle
Health-related information can be sensitive even when a user does not explicitly label it as medical data. Treat potentially sensitive health interactions conservatively.
