# CMS Specification

## Dashboard
Show:
- Draft count
- Pending review
- Scheduled posts
- Published posts
- Content needing review
- Comments awaiting moderation
- Newsletter statistics
- Recent activity
- System alerts

## Content management
CRUD for:
- Articles
- Pages
- Categories
- Topics
- Authors
- Reviewers
- FAQs
- Courses
- Lessons
- Campaigns
- Media
- Menus

## Article editor
Provide:
- Rich text editor
- Structured blocks
- SEO panel
- Featured image selector
- Inline media
- References
- Reviewer assignment
- Risk classification
- Publication scheduling
- Preview
- Revision history

## Media
Support:
- Upload
- Search
- Filters
- Folders/collections
- Alt text
- Caption
- Credit
- License
- Focal point
- Automatic image optimization
- Responsive variants

## Revisions
Every important content change should be traceable:
- Who changed it
- What changed
- When
- Previous version
- Current version

## Permissions
Use least privilege. Sensitive publishing operations should require appropriate roles.

## Moderation
Comments should support:
- Pending
- Approved
- Rejected
- Spam
- Escalated
- Blocked user

Never publish user-generated medical claims automatically without moderation rules.
