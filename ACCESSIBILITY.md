# Accessibility Requirements

Target WCAG 2.2 AA.

## Required
- Keyboard access
- Skip navigation
- Semantic landmarks
- Correct heading hierarchy
- Form labels
- Accessible errors
- Focus indicators
- Screen-reader compatibility
- Meaningful link text
- Alt text
- Captions/transcripts
- Sufficient contrast
- Responsive zoom
- Reduced-motion support
- No colour-only instructions

## Editorial accessibility
- Avoid giant text walls.
- Use descriptive headings.
- Define acronyms.
- Provide captions for important images.
- Avoid flashing or rapidly animated content.
