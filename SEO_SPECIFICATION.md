# SEO Specification

## Technical SEO
- Semantic HTML
- Crawlable links
- Canonical URLs
- XML sitemap
- Robots.txt
- HTTPS
- Redirect management
- 404 page
- Pagination handling
- Image optimization

## Article SEO
Each article should have:
- SEO title
- Meta description
- Canonical URL
- Open Graph data
- Social image
- Author
- Reviewer
- Date published
- Date modified
- Topic/category
- Structured data

## Health-content quality
Prioritize:
- Accuracy
- Author expertise
- Medical review
- References
- Clear authorship
- Updated dates
- Transparent editorial policies

Do not use keyword stuffing or misleading health claims.
